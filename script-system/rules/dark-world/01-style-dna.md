Only for The Dark World. Other channels never use these files.

## MODULE 1: LINGUISTIC STYLE DNA

### 1.1 Voice (స్నేహితుడితో మాట్లాడే curious explainer)
- రోజూ చూసే వస్తువు, tech, చరిత్రలోని సంఘటన వెనుక దాగిన science / logic ని సింపుల్‌గా విప్పి చెప్పాలి.
- Viewer ని ఎప్పుడూ **"మీరు / మీకు / మీ"** అని (గౌరవంగా, plural) పిలవాలి. `నువ్వు`, `విను`, `చెప్తా జాగ్రత్తగ విను` వద్దు.
- పాఠ్యపుస్తకం tone వద్దు; కఠిన గ్రాంథిక పదాలు వద్దు (Module 8 చూడండి).

### 1.2 Narrator Opinion Rule (నా అభిప్రాయం — తప్పనిసరి)
- ప్రతి Long script లో **1 నుండి 2 చోట్ల**, ప్రతి Short లో **1 చోట** narrator సొంత అభిప్రాయం సహజంగా రావాలి.
- రూపం ప్రతి script కి మారాలి (Module 9). ఉదాహరణ భావాలు: *"నిజం చెప్పాలంటే నాకు ఇందులో బాగా నచ్చేది..."*, *"నా ఉద్దేశంలో అసలు అద్భుతం ఇదే..."*, *"ఇది తెలిసినప్పుడు నాకు అనిపించింది..."*, *"నా దృష్టిలో ఈ ఆలోచన వెనుక ఉన్న తెలివి..."*.
- **Fact ముందు, Opinion తర్వాత.** Opinion ని fact లాగా చెప్పకూడదు.
- Opinion లో అనుమతి ఉన్నవి: ఆశ్చర్యం, engineering/ఆలోచనను మెచ్చుకోవడం, ఆలోచన రేపే ప్రశ్న.
- Opinion లో వద్దు: ఆరోగ్య సలహా, రాజకీయాలు, మతం, ఒక వ్యక్తి/సంస్థ మీద తీర్పు, భయపెట్టే అంచనాలు.

### 1.3 "దీన్నే X అంటారు. అంటే..." Term-Introduction Rule (కొత్త పదం పరిచయం)
- కొత్త పదం (English term) వచ్చినప్పుడు **వాక్యాన్ని నేరుగా "X అంటే..." తో మొదలుపెట్టకూడదు** — textbook definition లా వినిపిస్తుంది, screen label కి pause ఉండదు.
- **3-step flow:** (1) ముందు ఆ విషయాన్ని మామూలు మాటల్లో చెప్పాలి → (2) **"దీన్నే X అంటారు."** (full stop = audio gap, screen మీద X label pop-up కి) → (3) **"అంటే ... అనమాట."** తో అర్థం.
- ❌ *"రెండోది పొట్ట లోపల ఉండే Liver, పేగుల చుట్టూ దాక్కుని ఉంటుంది. Visceral fat అంటే మన కడుపు లోపలి అవయవాల మధ్యలో పేరుకుపోయే ఈ కొవ్వు పొర."*
- ✅ *"రెండోది పొట్ట లోపల ఉండే Liver, పేగుల చుట్టూ దాక్కుని ఉంటుంది. దీన్నే Visceral fat అంటారు. అంటే మన కడుపు లోపలి అవయవాల మధ్యలో పేరుకుపోయే ఈ కొవ్వు పొర అనమాట."*

### 1.4 "అనుకుందాం" Scenario Engine
- కష్టమైన concept ని ఒక ఊహా పరిస్థితితో వివరించాలి: *"...పెట్టారనుకుందాం"*, *"...ఉందనుకోండి"*.
- ఒక script లో గరిష్టంగా **రెండు** scenarios. ప్రతి scenario కి కొత్త పోలిక.

### 1.5 Connectors (sample నుండి — సందర్భాన్ని బట్టి మార్చి మార్చి వాడాలి)
- `అంటే...`, `కానీ`, `అందుకే`, `అయితే`, `ఇంకో విషయం`, `ముందుగా... ఆ తర్వాత...`, `ఉదాహరణకు`, `దాంతో`, `అలాగే`, `ఎందుకంటే`, `అసలు విషయం ఏంటంటే...`, `కానీ ఇక్కడ ఒక interesting విషయం ఉంది...`, `అన్నమాట`, `దెబ్బకు...`, `ఒక్కసారిగా`, `అసలు...`, `నిజం చెప్పాలంటే...`, `ఇప్పుడు చూద్దాం`.
- ఒకే connector తో వరుసగా రెండు వాక్యాలు మొదలు కాకూడదు.

### 1.6 Rhythm & Pacing
- **ఒక వాక్యం = ఒక స్పష్టమైన idea.** ప్రతి వాక్యానికి rigid పదాల లెక్క పెట్టకూడదు.
- **పొడవు మార్చి మార్చి:** మధ్యస్థ వివరణ వాక్యాలు (**పన్నెండు నుండి పద్దెనిమిది పదాలు**) మధ్యలో చిన్న punch వాక్యాలు (**మూడు నుండి ఆరు పదాలు**, ఉదా: *"దెబ్బకు అకౌంట్ ఖాళీ అయిపోతుంది!"*) కలపాలి.
- **ఒక వాక్యంలో గరిష్టం ఒక్క comma.** ఎక్కువ కావాల్సి వస్తే full stop (.) తో రెండు వాక్యాలుగా విడగొట్టాలి.
- ట్విస్ట్ ముందు, ఆలోచన మలుపులో `...` (మూడు చుక్కలు).
- ప్రతి 4 నుండి 6 వాక్యాలకు ఒక చిన్న curiosity ప్రశ్న.
- సహజ ముగింపులు: `-తుంది / -తాయి`, `ఉంటుంది`, `అవుతుంది`, `...అన్నమాట`, `...కదా?`.

### 1.7 Telugu-English Mixing
- Tech / science పదాలు English letters లో, మొదటి అక్షరం Capital: `Steel`, `Wi-Fi`, `GPS`, `Turbine`, `Router`, `Bluetooth`, `Pixel`, `Signal`, `Pressure`, `AI`, `GPU`, `Server`, `Data`, `Algorithm`, `Rocket`, `Orbit`, `Dark Web`, `Hackers`, `Model`, `Code` — ఎప్పుడూ Latin script, transliterate చేయకూడదు; తెలుగు పదాలు తెలుగు లిపిలోనే.
- English పదం + తెలుగు ప్రత్యయం మధ్య **ఒక space** తప్పనిసరి (ZWNJ కూడా వద్దు): ❌ `steelతో`, `phone‌కి` → ✅ `Steel తో`, `Phone కి`.


### 1.8 3-Step Storytelling Flow (ప్రతి concept ఇలా కట్టాలి)
- **వాక్యం 1 — Context + Everyday Simile:** Tech / AI / Space concept ని రోజువారీ పోలికతో పరిచయం చేయాలి (ఉదా: AI Model = సూపర్ ఫాస్ట్ మెదడు, Server = పెద్ద library, GPU = factory కి కరెంట్).
- **వాక్యం 2 — Action / Breakthrough:** ఆ technology అసలు ఏం చేస్తుందో సింపుల్ active క్రియలతో చెప్పాలి.
- **వాక్యం 3 — Direct Impact:** నిజ జీవితంలో వెంటనే వచ్చే ఫలితాన్ని విడిగా ఒక చిన్న punch వాక్యంలో చెప్పాలి (`దెబ్బకు...` తో మొదలుపెట్టొచ్చు).
- ఉదాహరణలు: `02-style-examples.md` PART D.

### 1.9 Problem → Solution Transition (4 angles, రొటీన్ template వద్దు)
- సమస్య/concept చెప్పి solution, action లేదా main tool కి వెళ్లేటప్పుడు `ఇక్కడే అసలు [Topic] పని మొదలవుతుంది`, `అప్పుడే అసలు మ్యాజిక్ మొదలవుతుంది` లాంటి translated AI templates ఎప్పుడూ వద్దు (`06-banned-words.md` Part A1).
- సందర్భాన్ని బట్టి ఈ 4 angles లో ఒకటి వాడాలి. ఒకే script లో, వరుస scripts లో ఒకే angle మళ్ళీ మళ్ళీ రాకూడదు:
  1. **Direct Need** (ఆ అవసరం ఎందుకో సూటిగా): *"దీన్ని తగ్గించడానికే మనకు Workout అవసరం అవుతుంది."*
  2. **Core Role / Impact** (దాని అసలు పాత్ర): *"ఈ లోపలి కొవ్వును కరిగించడంలోనే Workout అసలు పాత్ర ఉంటుంది."*
  3. **Question-to-Answer Bridge** (చిన్న ప్రశ్న → వెంటనే సమాధానం): *"మరి లోపల దాక్కున్న ఈ కొవ్వును కరిగించేది ఎలా? అక్కడే Workout హెల్ప్ చేస్తుంది."*
  4. **Reality Check / Support** (ఒకటి సరిపోదు, ఇది కూడా తోడవ్వాలి): *"ఈ కొవ్వును కరిగించాలంటే డైట్ ఒక్కటే సరిపోదు, Workout కూడా తోడవ్వాలి."*
- TTS: Telugu పదాలు Telugu script లో, English technical పదాలు (Workout, Visceral fat, AI, GPU) English script లో.

## MODULE 2: LEGACY SAMPLE FILTER (sample నుండి వదిలేయాల్సినవి)
1. Sample లోని వాక్యాలు, topics, facts, numbers ను copy చేయకూడదు — శైలి మాత్రమే.
2. Sample hook *"నాకు అంత టైం ఎక్కడిది అంటారా?... ఐతే చెప్తా జాగ్రత్తగ విను"* పూర్తిగా నిషేధం.
3. Sample లో ఎక్కువ రిపీట్ అయిన frames కి limits ఉన్నాయి (Module 8).
4. Sample లోని formatting (`###`, `**`, bullets, SECTION, 🔥 💬 emoji) వద్దు.
5. Sample లోని ఆరోగ్య claims, "అంట" gossip, భయపెట్టే పదాలు వద్దు (Module 3, Module 8).
