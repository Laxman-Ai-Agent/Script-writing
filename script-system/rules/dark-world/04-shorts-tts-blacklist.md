# The Dark World - Shorts, ElevenLabs TTS & Blacklist (Modules 6-8)
Only for The Dark World. Other channels never use these files.

## MODULE 6: SHORT SCRIPT నియమాలు & PLATFORM-SAFE CTAs
- **Target Length:** 135 నుండి 150 పదాలు (45 నుండి 55 సెకన్లు).
- **Content Focus:** Main script లోని అత్యంత ఆశ్చర్యపరిచే ఒకే ఒక twist లేదా logic.
- **Flow:** మొదటి 3 సెకన్లలో షాక్ నిజం / ప్రశ్న → "X అంటే..." → logic → ఒక opinion line (Module 1.2) → ending.
- వాయిస్‌లో ఒక source పేరు (ఉదా: `N-A-S-A`, `I-S-R-O`, అధికారిక report) ఒక చిన్న పదంలో.
- **YouTube Shorts Ending:** keyword comment అడగకూడదు. Topic కి కనెక్ట్ చేస్తూ Related Video క్లిక్ చేయమని ప్రతిసారీ కొత్త వాక్యం.
- **Instagram / Facebook Reels Ending:** న్యూట్రల్ keyword (`DARK`, `SCIENCE`, topic పదం) తో DM CTA, ప్రతిసారీ పదాలు మారుస్తూ. చివర్లో "ధన్యవాదాలు" / "Thank you" వద్దు.

## MODULE 7: ELEVENLABS TTS నియమాలు
1. తెలుగు పదాలు తెలుగు లిపిలో; tech / science / brand పదాలు English letters లో, మొదటి అక్షరం Capital.
2. **Suffix Space:** English పదం + తెలుగు ప్రత్యయం మధ్య ఒక space (❌ `Routerకి` → ✅ `Router కి`); ZWNJ వద్దు.
3. **Numbers:** అంకెలు అస్సలు వద్దు (`1946`, `1,500°C`, `23`, `50%`) — పూర్తి అక్షరాల్లో (`పంతొమ్మిది వందల నలభై ఆరు`, `పదిహేను వందల డిగ్రీలు`, `ఇరవై మూడు`, `fifty percent`).
4. **Acronyms:** సంస్థల short forms hyphens తో: `N-A-S-A`, `I-S-R-O`, `U-N`. రోజూ పలికే tech పదాలు (`GPS`, `LPG`, `Wi-Fi`) అలాగే.
5. ప్రతి 4–6 వాక్యాలకు ఒక curiosity ప్రశ్న; వాక్యం పొడవు, `...` పాజ్‌లు Module 1.6 ప్రకారం.

## MODULE 8: BLACKLIST & LIMITED FRAMES

- **టెక్స్ట్‌బుక్ / కఠిన గ్రాంథిక పదాలు (NEVER USE):**
  `నిర్దిష్ట`, `ఉపరితలంపై`, `విభజన`, `చొచ్చుకుపోతాయి`, `అప్రమత్తమై`, `అసౌకర్యం`, `అనుభూతి`, `నిరంతరం`, `సంచితమవుతాయి`, `క్షీణిస్తాయి`, `సంధానమవుతుంది`.
- **భయం / hype పదాలు (NEVER USE — calm tone only):**
  `దారుణంగా`, `భయంకరమైన`, `ప్రాణాంతకమైన`, `నిప్పులా`, `మృత్యువు`, `విలయం`, `scary`, `shocking`, `తిరుగుబాటు`, `షాక్ అవుతారు`.
- **Gossip / clickbait (NEVER USE):**
  `అంట`, `అంటారంట`, `నేను సీక్రెట్ చెప్పట్లేదు`, `నాకు అంత టైం ఎక్కడిది అంటారా?`, `ఐతే చెప్తా జాగ్రత్తగ విను`.
- **AI Clichés (NEVER USE):**
  `కీలక పాత్ర పోషిస్తుంది`, `లోతుగా పరిశీలిస్తే`, `లోతుగా తెలుసుకుందాం`, `ఇక్కడ గమనించాల్సిన ముఖ్యమైన విషయం ఏంటంటే`, `ఒక్క మాటలో చెప్పాలంటే`, `ఇప్పుడు మనం చూద్దాం`, `ఇది చాలా ముఖ్యం`, `చివరగా`, `ఈ వీడియో మీకు నచ్చిందని ఆశిస్తున్నాను`.
- **Limited Frames (sample లో ఎక్కువ రిపీట్ అయినవి — ఒక script లో గరిష్టం ఒక్కసారి, వరుసగా రెండు scripts లో రాకూడదు):**
  `...ఎప్పుడైనా ఆలోచించారా?`, hook లో `...తెలుసా?`, `సింపుల్‌గా చెప్పాలంటే`, `...చూద్దాం`, `ఇలాంటి ... కోసం channel follow అవ్వండి`, `అసలు విషయం ఏంటంటే`.
- **వాటి స్థానంలో:**
  - `దారుణంగా` / `భయంకరమైన` → `చాలా పెద్దగా`, `తీవ్రమైన`
  - `scary` / `shocking` → `ఆలోచించాల్సిన విషయం`, `ఆశ్చర్యపరిచే`
  - `సింపుల్‌గా చెప్పాలంటే` → `అంటే మొత్తం logic ఇదే...`, `ఒక్క లైన్‌లో అంటే...`
  - `నిర్దిష్ట` → `కచ్చితమైన`; `ఉపరితలంపై` → `పైన`; `నిరంతరం` → `ఆగకుండా`
