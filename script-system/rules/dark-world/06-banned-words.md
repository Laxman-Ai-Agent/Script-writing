- విధి ఆడిన వింత నాటకం → అనుకోకుండా జరిగిన ప్రమాదం / దురదృష్టం
- గూడుపుఠాణి → లోపల జరిగిన ప్లాన్ / దొంగ ప్లాన్
- ఒక్కసారిగా కలకలం రేగింది → అందరూ ఆశ్చర్యపోయారు / పెద్ద గొడవ అయ్యింది
- కాలగర్భంలో కలిసిపోయింది → కనుమరుగైపోయింది / ఎవరికీ గుర్తులేకుండా పోయింది
- ఈ మిస్టరీ వీడలేదు → ఇప్పటికీ దీనికి సమాధానం దొరకలేదు
