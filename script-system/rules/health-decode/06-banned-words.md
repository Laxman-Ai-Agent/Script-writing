# Health Decode - Banned Words List (Module 10)
Only for Health Decode. Every script, every situation: the left word NEVER appears; use a word from the right side.
New banned words the user gives later go into the matching section below (or a new section), nothing anywhere else.
Calm-tone rule (Module 2 / Module 3) still wins over any replacement here.

## 1. శరీర భాగాలు & లోపలి వ్యవస్థలు (Body Parts & Internal Systems)
- శ్వాసకోశ వ్యవస్థ / శ్వాసకోశం → ఊపిరితిత్తులు / Lungs
- జీర్ణవ్యవస్థ / జీర్ణక్రియ → కడుపు / అరుగుదల
- రక్తప్రసరణ వ్యవస్థ / రక్తప్రసరణ → రక్తం సరఫరా / రక్తం పారడం
- నాడీ వ్యవస్థ → నరాలు / Nerves
- కండరాల వ్యవస్థ → కండరాలు / Muscles
- అస్థిపంజర వ్యవస్థ → ఎముకలు / Bones
- విసర్జక వ్యవస్థ → ఒంట్లో చెడు బయటకు పంపే భాగాలు
- నాళాలు / రక్తనాళాలు → రక్తం వెళ్లే పైపులు / నరాలు
- ధమనులు / సిరలు → రక్తం వెళ్లే పైపులు / Arteries / Veins
- కాలేయం → Liver
- మూత్రపిండాలు → Kidneys
- క్లోమం → Pancreas
- ప్లీహం → Spleen
- పిత్తాశయం → Gallbladder
- మూత్రాశయం → Bladder
- అన్నవాహిక → ఆహార నాళం / గొంతు నుండి కడుపులోకి వెళ్లే పైపు
- వాయునాళం → గాలి గొట్టం / Windpipe
- కణాలు → Cells
- కణజాలం → కండరాలు / Tissues
- కీళ్లు → Joints
- మృదులాస్థి → మెత్తటి ఎముక / Cartilage
- మెదడు కణాలు → Brain Cells
- గుండె కవాటాలు → గుండె వాల్వ్‌లు / Heart Valves
- చర్మ రంధ్రాలు → చర్మానికి ఉండే చిన్న రంధ్రాలు / Pores
- శ్లేష్మ పొర → లోపలి మెత్తటి పొర / Mucus Membrane

## 2. జబ్బులు & ఆరోగ్య సమస్యలు (Diseases & Health Conditions)
- రక్తపోటు / అధిక రక్తపోటు → BP / హై బీపీ
- అల్ప రక్తపోటు → లో బీపీ / Low BP
- మధుమేహం → Sugar / షుగర్ జబ్బు
- రక్తహీనత → రక్తం తక్కువగా ఉండటం / ఒంట్లో రక్తం లేకపోవడం
- స్థూలకాయం → అధిక బరువు / లావుగా ఉండటం
- హృద్రోగం / గుండెపోటు → గుండె జబ్బు / Heart Attack
- పక్షవాతం → Paralysis / ఒక పక్క కాలు చెయ్యి పడిపోవడం
- మూర్ఛ → ఫిట్స్ / Fits
- ఉబ్బసం → ఆయాసం / Asthma
- క్షయవ్యాధి → TB
- కామెర్లు → పచ్చ కామెర్లు / Jaundice
- కీళ్లవాతం → కీళ్ల నొప్పులు / Arthritis
- అజీర్ణం → కడుపు ఉబ్బరం / అరుగుదల లేకపోవడం
- మలబద్ధకం → మోషన్ సరిగ్గా కాకపోవడం / Constipation
- అతిసారం → విరేచనాలు / Loose Motions
- నిర్జలీకరణం → ఒంట్లో నీళ్లు తగ్గిపోవడం / Dehydration
- నిద్రలేమి → నిద్ర పట్టకపోవడం / Insomnia
- మానసిక ఒత్తిడి → టెన్షన్ / Stress
- ఆందోళన → కంగారు / భయం / Anxiety
- కుంగుబాటు → బాగా దిగులుగా ఉండటం / Depression
- కణితి → గడ్డ / Tumor
- ప్రాణాంతక వ్యాధి → సీరియస్ అయ్యే జబ్బు (calm tone: "ప్రాణం తీసే", "డేంజర్" వాడకూడదు)
- దీర్ఘకాలిక వ్యాధి → చాలా ఏళ్లుగా వేధిస్తున్న జబ్బు / Chronic Disease
- వంశపారంపర్య వ్యాధి → పెద్దల నుండి వచ్చే జబ్బు / Genetic
- శ్వాస ఆడకపోవడం → ఊపిరి ఆడకపోవడం / ఆయాసం
- వాపు ప్రక్రియ → వాపు / లోపల వాపు (Inflammation)
- అలసట / నీరసం → బాగా అలసిపోవడం / ఒంట్లో సత్తువ లేకపోవడం
- మైకం / తలతిరగడం → కళ్లు తిరగడం / కళ్లు బైర్లు కమ్మడం

## 3. క్రిములు, వైరస్ & రోగనిరోధక శక్తి (Germs, Virus & Immunity)
- సూక్ష్మక్రిములు → పురుగులు / క్రిములు / Germs
- వ్యాధికారకాలు → జబ్బులు తెచ్చే క్రిములు / Virus / Bacteria
- అంటువ్యాధి / సంక్రమణ → ఒకరి నుండి ఒకరికి వచ్చే జబ్బు / Infection
- రోగనిరోధక శక్తి → జబ్బులతో పోరాడే శక్తి / Immunity
- ప్రతిరోధకాలు → జబ్బులతో పోరాడే కణాలు / Antibodies
- విషపదార్థాలు → చెడు పదార్థాలు / వ్యర్థాలు / Toxins
- కలుషితమైన → పాడైపోయిన / మురికిగా ఉన్న
- క్రిమిరహితం → శుభ్రంగా ఉన్న / Sterile
- వ్యాప్తి చెందుతుంది → పాకుతుంది / ఒకరి నుండి ఒకరికి వస్తుంది

## 4. వైద్య పరీక్షలు, మందులు & చికిత్స (Tests, Medicines & Treatment)
(Word swaps only; Module 3 zero-treatment rule still applies.)
- వ్యాధి నిర్ధారణ → జబ్బు ఉందో లేదో కనిపెట్టడం / టెస్ట్ చేయడం
- రక్త పరీక్ష → Blood Test
- మూత్ర పరీక్ష → Urine Test
- స్కానింగ్ / చిత్రీకరణ → Scan
- శస్త్రచికిత్స → ఆపరేషన్ / Surgery
- చికిత్స → వైద్యం / ట్రీట్‌మెంట్
- ఔషధాలు → మందులు / టాబ్లెట్లు
- మోతాదు → డోస్ / వేసుకోవాల్సిన లెక్క (Dose)
- దుష్ప్రభావాలు → సైడ్ ఎఫెక్ట్స్ / జరిగే నష్టాలు (Side Effects)
- నివారణ → రాకుండా ఆపడం / జాగ్రత్త పడటం
- రోగ నిరోధక టీకా → వ్యాక్సిన్ / Vaccine
- అత్యవసర పరిస్థితి → ఎమర్జెన్సీ / ప్రాణాపాయ స్థితి
- కోలుకోవడం → తగ్గిపోవడం / మళ్లీ మామూలు మనిషి అవ్వడం
- ఉపశమనం → నొప్పి తగ్గడం / కాస్త రిలీఫ్ రావడం

## 5. ఆహారం, పోషకాలు & శరీర ప్రక్రియలు (Food, Nutrients & Processes)
- ప్రాణవాయువు → మంచి గాలి / Oxygen
- బొగ్గుపులుసు వాయువు → చెడు గాలి / Carbon Dioxide
- పోషకాలు → బలాన్నిచ్చే విటమిన్లు / మంచి ఆహారం (Nutrients)
- పోషకాహార లోపం → సరైన తిండి లేకపోవడం / బలం తగ్గడం
- మాంసకృత్తులు → Protein
- పిండి పదార్థాలు → Carbs / అన్నం, రొట్టె లాంటివి
- కొవ్వు పదార్థాలు → కొవ్వు / Fats
- పీచు పదార్థాలు → పీచు / Fiber
- జీవక్రియ → ఒంట్లో ఆహారం శక్తిగా మారే పద్ధతి / Metabolism
- హార్మోన్లు → ఒంట్లో రసాయనాలు / Hormones
- జీర్ణరసాలు / జీర్ణ రసాలు → కడుపులో ఊరే రసాలు / Acids / Enzymes
- శోషణ → ఒంటికి పట్టడం / పీల్చుకోవడం (Absorption)
- విసర్జన → బయటకు వెళ్లిపోవడం (మలం, మూత్రం, చెమట ద్వారా)
- చెమట పట్టడం → ఒళ్లంతా చెమటలు కక్కడం
- రక్తం గడ్డకట్టడం → రక్తం గట్టిపడటం / Clot అవ్వడం

## 6. లక్షణాలు & వైద్య వర్ణనలు (Symptoms & Medical Descriptions)
- లక్షణాలు → సంకేతాలు / కనిపించే మార్పులు / Symptoms
- తీవ్రమైన → బాగా ఎక్కువగా / తట్టుకోలేనంత
- స్వల్పమైన → చిన్నపాటి / కొంచెం
- అకస్మాత్తుగా → ఒక్కసారిగా / ఉన్నట్టుండి
- క్రమంగా → మెల్లమెల్లగా / రోజురోజుకీ
- నిరంతరం → ఆగకుండా / ఎప్పుడూ
- అసాధారణమైన → మామూలుగా లేని / తేడాగా ఉన్న
- హానికరమైన → నష్టం చేసే
- ప్రయోజనకరమైన → మంచి చేసే / ఉపయోగపడే
- ప్రభావితం చేస్తుంది → దెబ్బతీస్తుంది / మార్చేస్తుంది
- క్షీణిస్తుంది / క్షీణిస్తాయి → తగ్గిపోతుంది / బలహీనపడుతుంది
