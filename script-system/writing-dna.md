# Writing DNA Profile — "The Dark World" (single narrator)

## 1. Identity

- Channel: **The Dark World**. One narrator, Telugu explainer channel.
- Topics: how-things-work tech, everyday science, nature/body, deep-time history, disasters, AI/tech news.
- Audience: general Telugu viewers, mobile-first. Assumes zero background; never talks down.
- Feel: a curious friend explaining something cool, with calm suspense. Not a lecturer, not a news anchor.

## 2. Voice rules (FIXED — never vary)

1. **Spoken Telugu (వ్యావహారికం)**, never గ్రాంథికం. "చేస్తారు", "వస్తుంది", "అనుకోండి" — not "చేయబడును", "వచ్చుచున్నది".
2. **Connected paragraphs, not one-liners.** (User correction 2026-11-09 — supersedes the old one-idea-per-line habit.) Group 3–6 sentences that belong to one beat into a paragraph; blank line between paragraphs. Mix short, medium and longer sentences. The script must read like one person talking continuously, not a list of separate statements.
3. **Telugu first, English only when Telugu speakers really say it in English.** (User correction 2026-11-09 — supersedes the sample-era heavy Tanglish.)
   - Use the everyday Telugu word whenever one exists: సున్నితమైన నరాలు (not sensitive nerves), స్పందిస్తాయి (not alert అవుతాయి), సంకేతం (not order/signal), వాయువు (not gas), పదునైన కత్తి (not sharp కత్తి), ద్రవ బిందువులు (not droplets), పరిశోధకులు (not scientists), కాసేపట్లోనే (not కొన్ని secondsలోనే), ఆసక్తికరమైన (not interesting).
   - Borrowed words that Telugu speakers use daily are written **in Telugu script**: సల్ఫర్, ఎంజైమ్‌లు, కార్నియా, హై-స్పీడ్ కెమెరా, కామెంట్.
   - **Latin script only** for proper names, brand/product names, scientific compound names and on-screen codes: Cornell University, Syn-Propanethial-S-oxide, Bluetooth, GPS, YES/NO.
   - Hybrid "English verb + చేస్తుంది/అవుతుంది" (decide చేస్తుంది, detect అవుతుంది) only when no natural Telugu verb exists. Prefer the Telugu verb.
   - Prefer plain spoken Telugu over sophisticated/Sanskritized words. "తాకనే తాకదు" beats both "touch చేయదు" and a bookish synonym.
4. **Inclusive "మనం"** for exploring together: "ఇప్పుడు చూద్దాం", "మనం రోజూ చూసే…". **"మీరు"** for addressing the viewer. Occasional intimate "విను / చూడు" only in playful hooks.
5. **Ellipsis "…" is the pause.** Used before reveals, after questions, in suspense. Em dash "—" for asides and punchy reveals.
6. **Hedge uncertain science honestly:** "scientists భావిస్తున్నారు", "అయి ఉండొచ్చు", "science దగ్గర ఇప్పటికీ పూర్తి answer లేదు".
7. **Cite sources in-voice, never as footnotes:** "OpenAI తర్వాత చెప్పిన ప్రకారం…", "Hugging Face forensic investigation ప్రకారం…", "scientists అంచనా ప్రకారం…".

## 4. Openings menu (VARIABLE — rotate; never repeat one of the last 3 used)

- **O1 Playful curiosity:** everyday question + "అంత టైం నాకు ఎక్కడిది అంటారా? అయితే చెప్తా జాగ్రత్తగా విను." (01, 02) — shorts only, rare.
- **O2 Paradox:** "ఇంత పెద్ద shipలో వేల టన్నుల బరువు ఉంటుంది. అయినా అది ఎందుకు మునగదు?" (03, 08, 06)
- **O3 Imagine scenario:** "ఒక్కసారి ఊహించుకోండి… మీరు ల్యాప్‌టాప్ ముందు కూర్చుని, కేవలం ఒక్క line టైప్ చేశారు. అంతే." (33, 25, 26, 27, 29)
- **O4 Shock cold-open:** the outcome first. "…ఆ result ఎంత దారుణంగా ఉందంటే, తర్వాతి planned test నే cancel చేసేసుకున్నారు." (18, 16, 32)
- **O5 Myth-first:** "X అనగానే చాలామందికి వెంటనే గుర్తొచ్చేది…" (12)
- **O6 Stacked-question teaser (news/long-form):** 2–4 rapid questions, then "ఇదంతా ఎలా జరిగిందో ఇప్పుడు చూద్దాం." (19, 20, 24)
- **O7 Deep-time scene:** "సుమారు 66 million years ago... Earth మీద వేల రకాల Dinosaurs జీవించేవి." (31, 23, 21)
- **O8 Hidden-in-plain-sight:** "రైలు పట్టాల మధ్య ఈ చిన్న gap ఎందుకు ఉంటుందో ఎప్పుడైనా గమనించారా?" (01, 13, 14)
- **O9 Casual greeting:** "హాయ్.. Black Hole అంటే ఏంటో తెలుసా?... తెలీదు కదూ... ఐతే ఇప్పుడు తెలుసుకుందాం." (28) — rare.
- **O10 Plain promise:** "ఈ వీడియోలో … step by step చూద్దాం." (11) — weakest; only if nothing else fits.

## 5. Body structures menu (VARIABLE — pick by topic, avoid last used)

- **S1 Process walk-through** (how X works / is made): ముందుగా → ఆ తర్వాత → ఇప్పుడు → ఇక్కడ → చివరికి. Carry one concrete example end to end. (04, 05, 11, 24, 26, 30, 17)
- **S2 Why-mystery → cause stack:** observation → wrong guess → real cause → second cause ("ఇంకో ముఖ్యమైన విషయం…") → modern twist. (01, 08, 09, 10, 13)
- **S3 Myth vs reality, two sides:** reputation → why → "కానీ ఇక్కడే ఈ storyకి మరో side ఉంది" → fair verdict. (12, 22)
- **S4 Timeline milestones:** "మొదటి 48 గంటల్లో:", "ఒక వారం తర్వాత:" … closing insight. (16)
- **S5 Disaster/event chronology:** calm before → trigger → escalation beats ("కానీ… అసలు ప్రమాదం…") → human cost → aftermath. (18, 31, 32)
- **S6 What-if cascade:** premise → effect 1 → "ఇక మరో పెద్ద సమస్య…" → "ఇంకో shocking విషయం…" → reality check ("ఇది నిజంగా జరగదు. కానీ…") → meaning. (27)
- **S7 Investigation reconstruction (long-form):** teaser → setup + jargon defs → step-by-step escalation with recaps → "అసలు interesting విషయం" → misconception correction → lesson. (19, 20)
- **S8 Deep-time journey:** hostile beginning → slow change → turning points → humans → open question. (21, 23)
- **S9 Concept via analogy → real example:** analogy first, then real object with numbers, then define units. (28, 33)

- **E1 Core insight reframe:** "అంటే … X కోసం కాదు… Y కోసం." (01, 03, 05, 09, 10)
- **E2 Poetic zoom-out:** "ఒక Asteroid Dinosaurs కథను ముగించింది. అదే సంఘటన... మనుషుల కథకు ఒక కొత్త అవకాశం ఇచ్చింది." (31, 21, 29)
- **E3 Lesson / warning:** "ఈ … మనకు చెప్పే lesson ఒక్కటే…" (19, 20)
- **E4 Practical tip:** "అందుకే … ఉంచాలి." (06, 13)
- **E5 Open mystery:** "ఆ ప్రశ్నకి ఇంకా పూర్తి సమాధానం లేదు…" (21)
- **E6 Wonder line:** "ఆ ఒక్క వర్షపు చుక్క వెనుక… ఇవన్నీ కలిసి పనిచేస్తున్నాయి." (29)

**CTA (one or two short lines after the ending; rotate):**
- Opinion question tied to topic → "కింద commentలో చెప్పండి." (most common)
- "ముందే తెలుసా? తెలుసుంటే YES, తెలియకపోతే NO అని comment చేయండి!"
- "మీ experienceని commentలో చెప్పండి."
- "ఇలాంటి … కోసం The Dark World channelని Subscribe చేయండి."
- "… మీ friendsకి share చేయండి."
Some samples end with no CTA — acceptable for serious/tragic topics (32).

## 7. Title line

Most samples start with a title line. Short: plain question ("Ship అంత బరువుగా ఉన్నా ఎందుకు మునగదు?"). Long: emoji + question + "| keywords Explained" ("✈️ విమానం అసలు ఎలా ఎగురుతుంది? | Engine, Wings, Lift, Turning Explained"). Emojis only in the title/CTA, never in the body.

## 9. Never

- గ్రాంథిక forms or heavy passive ("చేయబడినది"). Keep passive rare.
- English sentence order wearing Telugu words (calque). Test: would a Telugu person say it aloud this way?
- Bullet lists, headings, or stage directions inside the narration (title line excepted).
- Visual / b-roll cues. Narration text only.
- Emojis in the body.
- Overclaiming or fear-mongering beyond the facts; always the fair correction when popular belief is wrong.
- More than ~4 lines of pure exposition without a question, analogy, or twist.
- Reusing an opening or structure from the last 3 scripts (check `history.json`).
- Overusing connectors: నిజానికి, అయితే, దాంతో, అందుకే, మరి — each at most ~2 times per 300 words; never two consecutive sentences starting with the same word.
- Forced drama: suspense/twist phrases only where the content really turns. "ఆయుధం", "షాక్ అవుతారు" style words only if the fact is genuinely dramatic.
- Stronger certainty than the facts: if research says "may reduce", write "కొంతవరకు తగ్గవచ్చు", not "చాలా వరకు తగ్గుతాయి".
- Newsreader / textbook phrasing ("ఈ నేపథ్యంలో", "గణనీయంగా", "పేర్కొన్నారు") in normal narration.

## 10. Vocabulary bank (compressed from 34, 35 + observed)

- **Transitions:** ముందుగా, ఆ తర్వాత, ఇప్పుడు, ఇక్కడ, ఇంతలో, దాంతో, అందుకే, ఎందుకంటే, అంతేకాదు, దానికి తోడు, మరోవైపు, ఇక, చివరికి, అలా…
- **Bridges:** మరి…?, అసలు విషయం ఏంటంటే, విషయం ఏంటంటే, ఇక్కడే అసలు కథ మొదలైంది, ఇక్కడి నుంచే అసలు సమస్య మొదలైంది, అదే ఇక్కడ turning point అయింది
- **Explain:** అంటే, సింపుల్‌గా చెప్పాలంటే, ఉదాహరణకు, ఒక simple exampleతో చూద్దాం, … అనుకుందాం / అనుకోండి, దీన్ని ఇలా అర్థం చేసుకోవచ్చు
- **Suspense:** కానీ…, కానీ ఇక్కడే ఒక twist ఉంది, ఆ తర్వాత ఏం జరిగిందో తెలుసా?, ఇక్కడే అందరూ పొరబడ్డారు, అసలు నిజం వేరే ఉంది, ఫలితం మాత్రం షాకింగ్‌గా ఉంది
- **Scale:** వేల సంఖ్యలో, కోట్లాది, కొన్ని secondsలోనే, ఏకంగా, దాదాపు, సుమారు
- **Human reactions (sparingly):** అమ్మో!, భలే ఉంది కదా!, నిజంగా amazing కదా!, అయ్యో పాపం
- **Short spoken tags:** కదా, అంతే, అన్నమాట, అదీ సంగతి, అనమాట

## 11. Learned corrections (from user feedback — highest priority)

- 2026-11-09: Write connected paragraphs with mixed sentence lengths, not one-sentence lines (§2.2).
- 2026-11-09: Telugu words first; borrowed common words in Telugu script; Latin only for names/compounds (§2.3).
- 2026-11-09: Don't overuse నిజానికి / అయితే / దాంతో / అందుకే / మరి; vary sentence openings.
- 2026-11-09: Calm, natural tone over dramatic words; match hedging to the evidence.
- 2026-11-09: Priority order — natural human narration > fancy vocabulary > artificial storytelling.
- 2026-11-09: Use a key noun (e.g. వ్యవస్థ) only where it's really needed. On repeats, refer back with అది / ఇదే or name the specific thing (నరం, కండరం) instead of reusing the general word.

## 13. Gold reference script (user-written target quality — style only, NOT a fact source)

Read this before writing. Notice: paragraphs, varied sentence length, "ఎలా అంటే…" to open an explanation, "చూశారా…" to open the closing reframe, Telugu-script loanwords, calm hedging.

```
ఉల్లిపాయ కోస్తే కళ్లలో నీళ్లు ఎందుకు వస్తాయి?

ఉల్లిపాయ మన కంటికి చాలా దూరంలోనే ఉంటుంది… కత్తి కూడా కంటికి చాలా దూరంలోనే ఉంటుంది. కానీ ఉల్లిపాయ కోయడం మొదలుపెట్టగానే కాసేపట్లోనే కళ్లు మండటం, నీళ్లు రావడం మొదలవుతుంది. మరి అసలు ఉల్లిపాయలో ఏం జరుగుతుంది? మన కళ్ల నుంచి నీళ్లు వచ్చేలా అది ఎలా చేస్తుంది?

చాలామంది ఉల్లిపాయ రసం కళ్లలో పడటం వల్లే ఇలా జరుగుతుందని అనుకుంటారు. కానీ అసలు విషయం అది కాదు. మనం ఉల్లిపాయను కోయకముందు కళ్లను మండించే ఆ పదార్థం అందులో ఉండదు. ఉల్లిపాయను కోసినప్పుడే అది తయారవుతుంది.

ఎలా అంటే… ఉల్లిపాయలోని కణాల్లో సల్ఫర్ ఉన్న కొన్ని పదార్థాలు, వాటితో చర్య జరిపే ఎంజైమ్‌లు విడివిడిగా ఉంటాయి. మనం కత్తితో ఉల్లిపాయను కోసినప్పుడు ఆ కణాలు పగిలిపోతాయి. అప్పుడు ఈ పదార్థాలన్నీ ఒకదానితో ఒకటి కలుస్తాయి. దాంతో కొన్ని రసాయన మార్పులు జరిగి, చివరికి Syn-Propanethial-S-oxide అనే వాయువు తయారవుతుంది.

ఈ వాయువు గాల్లోకి వ్యాపించి మన కళ్ల దగ్గరికి చేరుతుంది. మన కంటిపై ఉండే కార్నియా అనే భాగంలో చాలా సున్నితమైన నరాలు ఉంటాయి. ఈ వాయువు వాటిని తాకగానే అవి వెంటనే స్పందిస్తాయి. వెంటనే మన కంటిలోని కన్నీటి గ్రంథులకు ఒక సంకేతం వెళ్తుంది. కంటికి ఇబ్బంది కలిగిస్తున్న ఈ పదార్థాన్ని బయటకు పంపించడానికి అవి ఎక్కువగా కన్నీళ్లను విడుదల చేస్తాయి. అందుకే ఉల్లిపాయ కోస్తున్నప్పుడు మనకు తెలియకుండానే కళ్లు నీళ్లతో నిండిపోతాయి.

మరి ఉల్లిపాయ ఇలా ఎందుకు చేస్తుంది? నిజానికి ఇది తనను తాను కాపాడుకునే ఒక పద్ధతి. ఉల్లిపాయను తినడానికి వచ్చే కొన్ని పురుగులు, జంతువుల నుంచి రక్షించుకోవడానికి ఈ రసాయన ప్రక్రియ ఉపయోగపడుతుంది.

ఇక్కడ ఇంకో ఆసక్తికరమైన విషయం ఉంది. 2025లో Cornell University పరిశోధకులు హై-స్పీడ్ కెమెరాతో ఉల్లిపాయను కోసినప్పుడు ఏం జరుగుతుందో పరిశీలించారు. కత్తి ఉల్లిపాయను తాకిన ప్రతిసారీ, దాని నుంచి చాలా చిన్న చిన్న ద్రవ బిందువులు బయటకు ఎగురుతున్నట్లు గమనించారు. వాటిలో కొన్ని సెకనుకు 40 మీటర్ల వేగంతో కూడా ప్రయాణించాయి.

ముఖ్యంగా మొద్దుబారిన కత్తితో ఉల్లిపాయను కోసినప్పుడు ఇలాంటి బిందువులు ఎక్కువగా బయటకు వస్తాయి. అందుకే పదునైన కత్తితో నెమ్మదిగా కోస్తే, ఉల్లిపాయ నుంచి బయటకు వచ్చే ఈ బిందువుల పరిమాణం తగ్గి, కళ్లలో నీళ్లు రావడం కూడా కొంతవరకు తగ్గవచ్చు.

చూశారా… మనం ఉల్లిపాయను కోస్తుంటే అది మనల్ని ఏడిపిస్తున్నట్లు అనిపిస్తుంది. కానీ అది తనను తాను కాపాడుకునే ప్రయత్నం చేస్తోంది. మనం మాత్రం మధ్యలో ఇరుక్కుపోతున్నాం అంతే!

మరి ఉల్లిపాయ కోసేటప్పుడు పదునైన కత్తి ఉపయోగిస్తే కళ్లలో నీళ్లు తగ్గుతాయని మీకు ముందే తెలుసా? తెలిసుంటే YES, తెలియకపోతే NO అని కామెంట్ చేయండి!
```

## 14. Health mode — "Health Decode" channel

Source: `sample script/Health-decode.txt` (28 health scripts + the user's own 7-point rubric). Use this section **in addition to** §1–§13 when the topic is health / body / disease / medicine. §2 voice rules and §11 corrections still apply (they are newer than these samples).

**Identity:** channel "Health Decode". Optional persona "AI డాక్టర్" ("హాయ్… నేను AI డాక్టర్‌ని…"). Explains how the body works and why diseases happen, for ordinary families. Calm, caring, never scary.

**Health openings (rotate, don't overuse the first):**
- H1 Signature: "…ఎందుకు వస్తుందో తెలుసా?… తెలీదు కదూ… ఐతే నేను చెప్తా!" — the channel's trademark, but max 1 in 3 scripts.
- H2 Everyday sighting: "మీ ఊర్లో ఎవరికైనా ఒక్క కాలు మాత్రమే పెద్దగా ఉబ్బిపోయి ఉండటం చూశారా?"
- H3 Fear-to-understanding: "Cancer అనే మాట వినగానే చాలామందికి భయం కలుగుతుంది. కానీ అసలు…"
- H4 Myth-first: "చాలామంది తలనొప్పి అంటే బ్రెయిన్ లోపలే నొప్పి అనుకుంటారు. కానీ బ్రెయిన్‌కి నొప్పి ఫీల్ చేసే సామర్థ్యమే లేదు!"
- H5 Known-but-unknown: "మలేరియా దోమ వల్ల వస్తుందని అందరికీ తెలుసు. కానీ ఆ దోమకి parasite ఎక్కడి నుంచి వస్తుందో తెలుసా?"
- H6 Series continuation: "Part 1లో … చూశాం. ఇప్పుడు …"

**Health explanation moves:**
- **Normal first, then what goes wrong:** explain how the healthy body works (kidney filters, insulin unlocks glucose, body temperature set point) BEFORE the disease. This is the channel's core structure.
- **Everyday analogies:** bone marrow = రక్త తయారీ ఫ్యాక్టరీ; glucose = బైక్‌లో వేసే fuel, insulin = mediator; DNA = instruction book; cancer = factoryలో start/stop/repair buttons పాడవడం; clot = పైప్‌లో గడ్డ; alveoli = gateway; dialyzer = మురికి నీటి filter.
- **Numbers to make it concrete:** 37°C → 39°C walk-through (fever), RBC lifespan ~120 రోజులు.
- **Define every medical term immediately:** "X అంటే …" (బోన్ మారో అంటే…, insulin resistance అంటే…).
- **Inner dialogue of the body:** "Brainకి ఇప్పుడు 'నాకు 39°C కావాలి… కానీ Body ఇంకా 37°Cలోనే ఉంది' అన్న పరిస్థితి."
- **Pre-empt the viewer's doubt:** "మరి మీకు ఒక డౌట్ రావొచ్చు…"
- **Balanced causes:** "దీనికి ఒక్క కారణం ఉండదు" + list of risk factors; "risk factor ఉందంటే తప్పనిసరిగా వస్తుందని కాదు".
- **Correct overgeneralisation:** "కాలు ఉబ్బింది కదా అని అది ఖచ్చితంగా ఫైలేరియానే అని అనుకోకూడదు."

**Health safety rules (mandatory):**
- Hedge outcomes: "రావచ్చు / ప్రమాదం పెరగొచ్చు / అవకాశం ఉంటుంది". Never promise cures or certainty.
- Symptoms / prevention scripts end with a doctor line: "self-diagnose చేసుకోకుండా doctorని consult అవ్వండి" or "doctor సలహాతో controlలో ఉంచుకోండి".
- No drug names, doses, or treatment instructions unless from an authoritative source (WHO, NIH, CDC, ICMR, NHS) and stated as general info.
- Sensitive topics (periods, reproduction, sexual health): factual, respectful, normalising ("ఇది వ్యాధి కాదు, సహజమైన ప్రక్రియ"). No jokes.

**Health CTAs (rotate):**
- Keyword-to-DM: "“CLOT” అని comment చేయండి. Link మీ DMలో వస్తుంది." (leads into the next/related topic)
- Next-part teaser: "…ఎలా తగ్గుతుంది? అదే Part 2లో చూద్దాం."
- Share-to-protect: "మీ ఇంట్లో ఎవరికైనా BP, Sugar ఉంటే… ఈ వీడియోను వాళ్లతో షేర్ చేయండి. ఒక్కసారి తెలుసుకోవడం… ఒక ప్రాణాన్ని కాపాడొచ్చు."
- Experience / topic request: "మీకు ఏ topic కావాలో comment చేయండి."

**Health rubric (user's own — run in Final validation for health scripts; every point must be ✅):**
1. Hook — first 2–3 lines grab with a question or striking fact (not a weak observation).
2. Simplicity — everyday Telugu words.
3. Term-explanation — every medical/technical term explained right away ("X అంటే Y").
4. TTS-friendly — sentences speakable for ElevenLabs: no very long chains, no stacked suffixes, short-to-medium sentences inside the paragraphs.
5. Why-it-matters stat — at least one genuine number/fact from WHO / research showing why it matters.
6. Specific CTA — exact action (comment keyword / share with family / consult doctor / follow), not generic.
7. Fact-check — medically accurate; no overclaim or misleading statement.

**Note on language:** these health samples use heavy Latin-script English (Body, Brain, Heart, blood). The user's newer §2.3 / §11 corrections win: Telugu words first (శరీరం, మెదడు, గుండె, రక్తం), daily loanwords in Telugu script, Latin only for proper medical names when the Telugu one is unfamiliar (Plasmodium, Type-2 diabetes, Dialyzer).
